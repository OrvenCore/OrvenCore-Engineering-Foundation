# Brand Asset Notice

The two SVG files in this directory are exact, unmodified copies of the approved OrvenCore **Open Joint** production logo system:

- `orvencore-horizontal-light.svg` — Orven Blue 600 (`#4657D5`) and Core Ink (`#111820`)
- `orvencore-horizontal-dark.svg` — Orven Blue 400 (`#7C88FF`) and white (`#FFFFFF`)

The official wordmark is supplied as vector outlines and requires no font installation. Its starting typeface was URW Gothic Demi from the URW Base 35 collection, distributed under the GNU Affero General Public License version 3 with a font exception. The font software is not bundled here. The wordmark contours were outlined and optically spaced for the OrvenCore identity.

Do not typeset or recreate the logo. For normal OrvenCore product, interface, website, and documentation typography, use **Geist** according to the [OrvenCore Brand repository](https://github.com/OrvenCore/brand).

These assets contain vector paths only: no font references, scripts, raster images, gradients, filters, or external resources.
